# Wheather-Predict
Weather-Predict is a dynamic weather forecasting website that predicts the weather for the next day and displays a graphical representation of the forecast. The website fetches real-time weather data, processes it, and provides an intuitive interface to users.
Features:
Real-Time Weather Forecasting: Predicts the next day's weather using live data.
Graphical Representation: Visualizes weather data on interactive graphs.
Responsive Design: Designed to work seamlessly across different devices (desktop, tablet, mobile).
Search History: Tracks and displays the search history of user queries.
